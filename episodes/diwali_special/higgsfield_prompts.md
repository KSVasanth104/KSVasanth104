# Diwali Special: Higgsfield prompts (paste-ready)

Companion to [script.md](script.md). Same shots and lines, rewritten for Higgsfield's web app.
Midjourney flags (`--ar`, `--v`, `--oref`) are removed: set those in Higgsfield's settings instead.

## Workflow (2 steps per shot)

1. **Image:** open Higgsfield's **Image** tool and choose a high-quality image model. Set the
   aspect ratio to **9:16**. Paste the **Image prompt**. Generate, then choose the best take.
2. **Video:** click the chosen image's **Animate** option, or open **Video** and upload the image.
   Choose a model that makes **sound and speech** (Veo 3.1 or Kling 3, if your plan has them), set
   **9:16**, and use the shortest duration available. Paste the **Video prompt**. Generate.
3. Download each clip as `episodes/diwali_special/clips/shotXX.mp4` and edit in CapCut using the
   edit notes and `subtitles.srt` from the script.

**Why two steps:** starting from an approved image keeps every deity's iconography correct.
Text-only video models often get the tusk, arms or vahana wrong.

**Saving credits:** test **Shot 02 (Ganesha)** first. If the look is right, run the rest.
If the speech comes out wrong, generate the video **without speech** (delete the line in quotes)
and add the ElevenLabs voice in CapCut instead.

**Style line** (already included in every image prompt):
`2D Indian cartoon animation style, soft cel shading, clean bold outlines, warm vibrant colors, expressive big eyes, gentle golden lighting, storybook feel, high detail background, cinematic lighting, vertical 9:16 composition`
